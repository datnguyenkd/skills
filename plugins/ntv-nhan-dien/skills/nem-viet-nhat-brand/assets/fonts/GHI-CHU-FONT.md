# Font SVN-Gilroy — bộ 16 file kèm trong gói

Font SVN-Gilroy (Thin → Black, thẳng + nghiêng) là font công ty đã mua bản quyền, **kèm ở đây để dùng nội bộ
Nệm Thuần Việt / Nệm Việt Nhật** — không mua bán, không phát hành lại cho mục đích khác.

- Cài vào máy (per-user, không cần admin): `python3 scripts/install_fonts.py` → mở lại PowerPoint/Keynote.
- Script catalogue đọc thẳng font trong thư mục này; module dựng slide gọi font theo tên, cần cài để PowerPoint hiện đúng.
